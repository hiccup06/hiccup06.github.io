# Hiccup's Plugins

My plugins and modifications for Revenge.

## How to install?

Copy a plugin or tweak URL and paste it into the Plugins page in Revenge.

For plugins:
```
https://hiccup06.github.io/plugins/<PLUGIN_NAME>/
```

For forks & tweaks:
```
https://hiccup06.github.io/tweaks/<PLUGIN_NAME>/
```
