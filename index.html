Hiccup's Plugins

A collection of plugins and modifications for Revenge, maintained by Hiccup.

Installation

To install a plugin, copy its URL and paste it into the Plugins page in Revenge. Plugin URLs follow this format: 

https://hiccup04.github.io/Hiccup-Plugins/<PLUGIN_NAME>/

Available plugins

  • More Alts! - A visual overhaul of the original More Alts plugin, featuring a Material 3-inspired interface while retaining its original functionality.
    Originally created by Win8.1VMUser, John and cocobo1. Modified by Hiccup.

Maintainer

  • Hiccup - Plugin modifications, interface design and development.

Original plugin authors and contributors are credited in their respective plugin entries and manifests.

Distribution

Use the official installation URLs listed on this page when installing these plugins. Verify plugin sources before installing modifications from third parties.
